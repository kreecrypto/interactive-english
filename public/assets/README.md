# Runtime assets

Only approved, web-ready assets belong here.

Recommended structure:

```text
assets/
  images/
    L01/
    L08/
    L12/
  audio/
    L01/
    L08/
    L12/
  models/
    L08/
    L12/
```

Google Drive remains the master/review location. Do not use Drive links as the production runtime asset CDN.
